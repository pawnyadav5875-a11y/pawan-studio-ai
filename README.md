# PAWAN STUDIO AI

### Your Professional AI Creative Studio

Professional browser-based AI editing studio.

## Features

- AI Background Remover
- Magic Eraser
- AI Image Generator
- YouTube Thumbnail Generator
- Before / After Preview
- HD PNG Download
- Mobile Responsive Design
- Progressive Web App
- Hindi + English interface

## Technology

- Python Flask
- HTML5
- CSS3
- JavaScript
- IMG.LY AI
- Pollinations AI

## Run Locally

```bash
pip install -r requirements.txt
python app.py
```

Open: http://localhost:7860

## Privacy

Image editing is performed locally in the browser.
The Flask server does not store uploaded images.
Image generation sends prompts to an external provider.
